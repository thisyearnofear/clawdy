# Retired: Marble-Only Pivot Plan

The standalone Marble driving-arena approach is retired. It is not an alternative product or an implementation backlog.

The sole active direction is **Clawdy: Train Your Champion**, an agent-training league in a generated physical world. See the [canonical product and implementation plan](HACKATHON.md).

World Labs remains the environment-generation component of that plan. Existing assets and their validation requirements are documented in the [world asset guide](../public/marble/README.md).

This path remains only to direct old references to the current plan. Git history preserves the former document. Retiring the plan does not itself remove legacy code or verify that the current world is playable.
