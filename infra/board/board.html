The loop

Coach it. Train it. Let go.

Play→Call→Replay→Coach→Train→Match→Forge→Print

A small neural policy is trained on the lessons you approve, then runs a held-out arena with coaching locked. Signed-in players submit their brain to a ladder the server runs itself, so scores cannot be faked from the browser.

Code coaches welcome: write a teacher function, npm run teacher:run, import the checkpoint.
